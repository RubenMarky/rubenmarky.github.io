# 🌐 Plataforma TIC - 3° Año CBS

Este repositorio contiene la plataforma web educativa para la materia **Tecnologías de la Información y la Comunicación (TIC)** de **3° Año CBS** en el **C.E.P. N° 38** de Jardín América, Misiones.

## 🚀 Características
*   **Diseño Futurista / Cyberpunk:** Interfaz moderna en modo oscuro optimizada para estudiantes de secundaria.
*   **Estructura Modular:** Organización limpia por unidades de aprendizaje (Ciudadanía Digital, IA, Ciberseguridad).
*   **Identidad Institucional:** Escudo tecnológico del C.E.P. N° 38 integrado en la cabecera.
*   **Código Limpio:** Desarrollado exclusivamente con HTML5 y CSS3 nativo.

## 📁 Estructura del Proyecto
```text
├── index.html       # Estructura principal de la plataforma
├── style.css        # Estilos visuales, animaciones y glassmorphism
└── escudo.png       # Imagen del escudo institucional futurista
```

## 🛠️ Tecnologías Utilizadas
*   **HTML5:** Semántica y maquetación web.
*   **CSS3:** Flexbox, CSS Grid, variables y efectos visuales avanzados.
*   **Google Fonts:** Fuentes tipográficas modernas.
