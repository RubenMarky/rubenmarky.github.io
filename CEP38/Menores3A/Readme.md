# 📡 Plataforma TIC — C.E.P. N° 38

Rediseño de la interfaz para la materia **TIC (3° Año CBS)** del **C.E.P. N° 38** (Jardín América, Misiones), con estética moderna EdTech y Glassmorphism.

## 📚 Unidades del Plan de Estudios (2026)
1.  **Ciudadanía Digital:** Identidad, huella y ciberbullying.
2.  **Inteligencia Artificial:** Machine Learning y uso crítico.
3.  **Ciberseguridad:** Amenazas y protección.
4.  **Producción Digital:** Diseño y licencias CC.
5.  **TIC y Futuro:** IoT y síntesis del CBS.

## 🚀 Tecnologías
*   HTML5 semántico.
*   CSS3 avanzado (Grid, Flexbox, desenfoque).
*   Google Fonts (Plus Jakarta Sans).
