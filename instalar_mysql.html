MySQL 8.0

Guía rápida para Windows · MySQL Server + Workbench · Sin errores de puerto ni contraseñas perdidas

MySQL 8.0.46 Windows ~20 minutos Server + Workbench
📥

Instalación

Descargar el instalador correcto y dejar el servidor corriendo

Descargá el instalador

  1. Buscá MySQL en Google y entrá al sitio oficial mysql.com.
  2. Hacé clic en DOWNLOADS, en el menú de arriba.
  3. Bajá hasta el final y seleccioná MySQL Community (GPL) Downloads.
  4. Elegí MySQL Installer for Windows.
  5. Confirmá que la versión sea 8.0.46.
ArchivoPesoUsalo si…
mysql-installer-web-community-8.0.46.0.msi 2.1 MB ❌ Necesita internet activa todo el proceso. Se puede cortar a mitad de camino.
mysql-installer-community-8.0.46.0.msi 565.9 MB ✅ Trae todo incluido. Instalá sin depender de tu conexión.
📥

Elegí siempre la opción pesada~565.9 MB es la única forma de evitar que la instalación se corte por falta de internet.

Instalá paso a paso

  1. Hacé doble clic en el archivo descargado.
  2. En "Choosing a Setup Type", elegí Developer Default (servidor + herramientas, recomendado) o Server only (solo el motor).
  3. Hacé clic en Next.
  4. Si falta algo (ej. Microsoft Visual C++), hacé clic en Execute para instalarlo.
  5. Cuando todo diga Ready, hacé clic en Next.
  6. En la pantalla de productos, hacé clic en Execute y esperá.
  7. Hacé clic en Next para pasar a la configuración.
⚙️

Configuración

Dos puntos críticos — todo lo demás se deja como viene por defecto

Tipo de servidor y puerto

  1. En Config Type, dejá Development Computer — es la ideal para tu PC.
  2. Mirá el campo Port.
🔑

Punto crítico — el puertoEl puerto correcto es 3306. Si la pantalla muestra 3307, borralo y escribí 3306 a mano antes de seguir. Con el puerto equivocado, Workbench después no va a encontrar tu servidor.

  1. Hacé clic en Next.

Contraseña de Root

  1. En Authentication Method, dejá tildado Use Strong Password Encryption (recomendado).
  2. Escribí tu contraseña en MySQL Root Password y repetila en Repeat Password.
🔑

Punto crítico — guardá tu contraseña ya mismoEsta contraseña abre las puertas a todas tus bases de datos. Anotala en un lugar seguro antes de seguir. Si la perdés, no hay forma de recuperarla: hay que desinstalar todo y empezar de cero.

  1. Dejá en blanco MySQL User Accounts por ahora. Podés crear usuarios más adelante.
  2. Hacé clic en Next.

Servicio de Windows

  1. Verificá que esté tildada Configure MySQL Server as a Windows Service.
  2. Dejá el nombre por defecto: MySQL80.
  3. Dejá tildada Start the MySQL Server at System Startup, así arranca solo con tu PC.
  4. Hacé clic en Next.

Aplicar y terminar

  1. Hacé clic en Execute en la última pantalla.
  2. Esperá a que todos los pasos tengan un ✅ verde.
  3. Hacé clic en Finish, y después Next hasta cerrar el asistente.

¡Listo! Ya tenés MySQL Server y Workbench instalados y funcionando. 🎉

🗑️

Desinstalación total

Una desinstalación normal no alcanza — hay que ir a buscar las carpetas escondidas

Paso 1 — Desinstalar los programas

  1. Cerrá el instalador si está abierto.
  2. Abrí Panel de control → Programas y características.
  3. Desinstalá todo lo que diga MySQL: Server, Workbench, Router, Installer, Shell.

Paso 2 — Borrar las carpetas ocultas

⚠️

Alerta — paso obligatorio, no lo salteesSi no borrás estas carpetas, Windows recuerda tu configuración vieja (contraseña incluida) y el error vuelve a aparecer apenas reinstales.

  1. Presioná Windows + R.
  2. Escribí %programdata% y presioná Enter.
  3. Buscá la carpeta MySQL y eliminala por completo.
  4. Presioná Windows + R otra vez.
  5. Escribí %appdata% y presioná Enter.
  6. Si aparece una carpeta MySQL, eliminala también.

Paso 3 — Borrar los archivos del programa

  1. Andá a C:\Program Files y borrá la carpeta MySQL.
  2. Andá a C:\Program Files (x86) y borrá la carpeta MySQL si existe.

Paso 4 — Reiniciar

Reiniciá tu computadora y ejecutá el instalador de nuevo. Esta vez va a pedir crear la contraseña desde cero, sin ningún error.

MomentoQué no podés saltear
Al descargarElegí el archivo de ~565.9 MB, no el de 2.1 MB
Al configurarPuerto 3306 (no 3307)
Al configurarAnotar la contraseña de Root en un lugar seguro
Al desinstalarBorrar %programdata% y %appdata%
