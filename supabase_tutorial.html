¿Qué es Supabase y por qué importa?

El "Firebase de código abierto" que usan las startups modernas

Hasta ahora usaste MySQL Workbench instalado en las PC del laboratorio. Funciona genial para aprender, pero la base vive solo en esa máquina. Si querés que una app de celular o una web se conecte a tus datos desde cualquier lado, necesitás una base de datos en la nube.

Supabase es justamente eso: alguien ya instaló, configuró y mantiene un servidor PostgreSQLSistema de base de datos relacional, primo hermano de MySQL. Usa tablas, claves primarias y foráneas.≈ MySQL — el 90% del SQL funciona igual profesional, y te lo regala listo para usar desde el navegador.

⚡ Lo que necesitás saber
Gratis para hasta 2 proyectos · Usa PostgreSQL (relacional, como MySQL) · Incluye base de datos, login de usuarios y APIs automáticas · Todo desde el navegador, incluso el celu.

La gran diferencia con Firebase: mientras Firebase usa NoSQL, Supabase usa una base de datos relacional con Foreign KeysClave foránea: enlaza una tabla con otra para mantener los datos conectados y coherentes.= MySQL FOREIGN KEY (idéntico) y Primary KeysClave primaria: identifica de forma única cada fila de una tabla.= MySQL PRIMARY KEY (idéntico)… exactamente lo que ya dominás.

Diseñar las tablas

Crear usuarios y videojuegos con la interfaz visual

›

Vamos a crear la base TechPlay Cloud: dos tablas relacionadas (1:N) para gestionar usuarios y sus videojuegos favoritos.

1
En la barra lateral, clic en Table Editor ("Editor de Tablas").
2
Clic en New table. Nombre: usuarios.
3
Supabase ya crea id y created_at solos. Agregá las demás columnas con Add column:
ColumnaTipoQué guarda
nombre_usuariotextEl nick (ej: GamerPro_99)
emailtextCorreo, único por usuario
edadint4Edad (número entero)

Tipos modernos de PostgreSQL
text = VARCHAR · int4 = INT · uuid = id único universal · timestamptz = fecha y hora con zona horaria.
4
Clic en Save. Repetí para crear la tabla videojuegos con: titulo (text), plataforma (text), horas_jugadas (int4) y id_usuario (int8).

Cargá datos con Insert → Insert row. En videojuegos, poné en id_usuario el id de un usuario que ya exista.

Fase 4

Consultas en el SQL Editor

Comprobar que el SQL funciona igual que en Workbench

›
1
En la barra lateral, clic en SQL Editor ("Editor SQL").
2
Clic en New query y pegá el script de abajo.
3
Clic en Run ("Ejecutar") o presioná Ctrl + Enter. ¡Vas a ver tus datos abajo, igual que en Workbench!

Script SQL — crea todo de una vez

-- TechPlay Cloud: pegá esto en el SQL Editor y dale Run

CREATE TABLE usuarios (
    id             BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    nombre_usuario TEXT        NOT NULL,
    email          TEXT        NOT NULL UNIQUE,
    edad           INT,
    pais           TEXT,
    created_at     TIMESTAMPTZ DEFAULT now()
);

CREATE TABLE videojuegos (
    id            BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    titulo        TEXT        NOT NULL,
    plataforma    TEXT,
    horas_jugadas INT         DEFAULT 0,
    id_usuario    BIGINT      REFERENCES usuarios(id),
    created_at    TIMESTAMPTZ DEFAULT now()
);

-- Datos de prueba
INSERT INTO usuarios (nombre_usuario, email, edad, pais) VALUES
    ('GamerPro_99',  'gamer99@mail.com', 17, 'Argentina'),
    ('NoobMaster',   'noob@mail.com',    16, 'Argentina'),
    ('QueenOfFPS',   'queen@mail.com',   17, 'Brasil');

INSERT INTO videojuegos (titulo, plataforma, horas_jugadas, id_usuario) VALUES
    ('God of War Ragnarök',      'PS5',    120, 1),
    ('Halo Infinite',            'Xbox',   60,  2),
    ('The Legend of Zelda TotK', 'Switch', 200, 3);

-- Verificación con JOIN (¿te suena de TechPlay Store?)
SELECT u.nombre_usuario, v.titulo, v.plataforma, v.horas_jugadas
FROM videojuegos v
INNER JOIN usuarios u ON v.id_usuario = u.id
ORDER BY v.horas_jugadas DESC;
🎉 ¡Lo lograste!
Si la última consulta te devuelve resultados, creaste una base de datos relacional en la nube y comprobaste que el SQL de MySQL funciona casi idéntico en PostgreSQL. Un paso enorme hacia el desarrollo profesional.
