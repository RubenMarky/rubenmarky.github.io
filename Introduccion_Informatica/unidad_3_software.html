00Presentación de la unidad

Hasta ahora vimos los «fierros» de la computadora (Unidad 2) y los fundamentos de la información (Unidad 1). Pero una computadora con todos sus componentes físicos perfectamente armados, sin software, no sirve para nada: es una caja inerte. El software es lo que le da vida.

En esta unidad vamos a ver qué es el software, cómo se clasifica, qué hace un sistema operativo, y —algo que va a cambiar tu manera de usar la computadora para siempre— cómo organizar archivos y carpetas para no perder nunca más un documento.

Es la unidad más práctica del primer cuatrimestre: vas a abrir muchas ventanas, mover archivos, instalar y desinstalar programas. Si en la Unidad 2 te sentiste con muchos conceptos abstractos, esta te va a devolver al terreno de lo concreto.

  • Qué hace un sistema operativo y cuáles son los más usados.

  • Cómo se mueven el escritorio, las ventanas y los menús.
  • Qué son los archivos, las carpetas, las rutas y las extensiones.
  • Cómo comprimir y descomprimir archivos (los famosos .zip).
  • Cómo instalar y desinstalar programas correctamente.
  • Qué es un usuario, qué son los permisos, y por qué importan.
  • Cómo configurar la accesibilidad para distintas necesidades.

01¿Qué es el software?

En la unidad anterior vimos que el hardware es todo lo físico. El software es exactamente lo opuesto: son las instrucciones que le dicen al hardware qué hacer. No tiene cuerpo. Es información pura, guardada en algún lado.

Una definición práctica: el software es el conjunto de programas, instrucciones y datos que le permiten a una computadora hacer cosas útiles.

Cómo se clasifica el software

Aunque hay muchísimos tipos de programas, se agrupan en tres grandes categorías:

a) Software de base (o de sistema)

Es el más importante: sin él, la computadora no arranca. El sistema operativo (Windows, Linux, Android, iOS) entra acá. También los drivers o controladores, que son pequeños programas que enseñan al sistema operativo cómo hablar con un dispositivo específico (la impresora, la placa de video).

b) Software de aplicación

Son los programas que vos usás directamente para hacer cosas concretas. WhatsApp, Word, Excel, Chrome, Spotify, Photoshop, los videojuegos. Vienen y se van: podés instalarlos y desinstalarlos sin que la computadora deje de funcionar.

c) Software de programación

Son herramientas pensadas para que los programadores creen otros programas. Editores de código, compiladores, entornos de desarrollo. Los vas a ver en 2° y 3° año cuando empieces a programar.

🚗 Una analogía con un auto
  • Motor, transmisión, frenos: software de base. Sin ellos, el auto no anda.
  • Radio, aire, GPS: software de aplicación. Le suman utilidad, pero si los sacás, el auto sigue andando.
  • Herramientas del mecánico: software de programación. Sirven para crear o mantener todo lo demás.

02El sistema operativo: el gran director de orquesta

De todos los tipos de software, el más importante es el sistema operativo (SO). Es el primero que se carga cuando prendés la computadora y el último que se cierra cuando la apagás. Mientras tanto, está siempre presente, aunque no lo veas.

¿Qué hace exactamente?

  • Decide qué programa usa el procesador en cada momento.
  • Reparte la memoria RAM entre todos los programas abiertos.
  • Gestiona los archivos y carpetas del disco.
  • Habla con los dispositivos conectados: teclado, mouse, impresora, pantalla.
  • Administra los usuarios y sus permisos.
  • Te ofrece una interfaz (ventanas, menús, íconos) para que interactúes.

El sistema operativo es el intermediario entre vos y el hardware. Vos no le hablás directamente al procesador ni al disco. Le hablás al SO, y él se encarga de traducir tus pedidos.

🎼 Una metáfora útil

Pensá en un director de orquesta. La orquesta son los componentes (procesador, memoria, disco, periféricos). Cada músico sabe tocar su instrumento, pero si todos tocaran lo que quieren al mismo tiempo, sería un caos.

El director (el SO) decide quién toca cuándo, controla los tiempos, da entradas. Sin director, la orquesta no puede tocar una sinfonía. Sin sistema operativo, la computadora no puede ejecutar ni el programa más simple.

🏆 ¿Cuál es el mejor sistema operativo?

Ninguno es «el mejor» en abstracto: cada uno es mejor para ciertas cosas. Windows tiene compatibilidad con todo, Linux es libre y muy estable para servidores, macOS está pulido para creatividad, Android domina la movilidad, iOS apuesta a la seguridad cerrada.

El SO es una capa intercambiable. Una vez que entendiste cómo funciona uno, los demás se aprenden rápido: cambian los nombres y los colores, pero los conceptos son los mismos.

03Software libre vs. software propietario

Uno de los temas más interesantes del software no es técnico, sino filosófico y legal: quién es dueño del programa y qué puede hacer cada uno con él.

Software propietario

Es aquel que pertenece a una empresa o persona, que conserva todos los derechos. Vos lo podés usar (a veces gratis, a veces pagando una licencia), pero no podés ver cómo está hecho por dentro, no podés modificarlo, y no podés redistribuirlo libremente.

Ejemplos: Windows, Microsoft Office, Photoshop, AutoCAD, los juegos comerciales.

Software libre

Es aquel que respeta las llamadas cuatro libertades del software:

Libertad 0
Usar

Usar el programa para cualquier propósito.

Libertad 1
Estudiar

Estudiar cómo está hecho (acceso al código fuente).

Libertad 2
Modificar

Modificarlo y adaptarlo a tus necesidades.

Libertad 3
Redistribuir

Compartirlo, con o sin modificaciones.

Software libre no es lo mismo que software gratuito. Aunque casi todo el software libre es gratis, lo importante es la libertad para usar, modificar y compartir, no el precio.

Ejemplos: GNU/Linux, LibreOffice, Firefox, GIMP (alternativa libre a Photoshop), VLC, Scratch.

¿Por qué importa esto?

  • Económica: el software libre es gratuito. Una escuela o emprendimiento puede equiparse sin gastar fortunas en licencias.
  • Soberanía: no depender de empresas extranjeras para algo tan básico como una computadora.
  • Educativa: al poder ver el código, los estudiantes aprenden cómo funcionan las cosas por dentro.
  • Ética: el conocimiento se comparte en vez de cerrarse.

Creative Commons

La idea del software libre se extendió a textos, música, fotos, videos. Las licencias Creative Commons (CC) permiten a un autor decir: «podés usar mi obra, con tal condición». Por ejemplo: «citá mi nombre» (CC BY) o «no para fines comerciales» (CC BY-NC).

Esto es importantísimo para no robar trabajos ajenos sin querer. Wikipedia, por ejemplo, usa Creative Commons: podés copiar contenido siempre que aclares de dónde lo sacaste.

🎯 Una opción de doble vida

En esta materia te vamos a mostrar las herramientas en sus dos versiones cuando sea posible: las propietarias (Microsoft Word, Excel) y las libres (LibreOffice Writer, Calc). Así podés trabajar tanto en una compu del trabajo con Windows, como en una con Linux en tu casa, sin atarte a una sola tecnología.

04El escritorio, las ventanas y los menús

Aunque Windows, macOS y las versiones modernas de Linux parecen distintos a primera vista, comparten una misma idea: lo que llamamos interfaz gráfica. Todo se maneja con ventanas, íconos, menús y el puntero del mouse.

Los elementos del escritorio

  • Escritorio: la pantalla principal que ves cuando arranca el sistema. Funciona como tu mesa de trabajo.
  • Íconos: imágenes pequeñas que representan archivos, carpetas o accesos directos.
  • Barra de tareas (Windows) / Dock (macOS) / Panel (Linux): la franja con accesos rápidos y las ventanas abiertas.
  • Menú de inicio: donde están listados todos los programas instalados.
  • Área de notificaciones: muestra el reloj, el WiFi, la batería, los avisos del sistema.

Cómo se manejan las ventanas

Cada programa que abrís corre adentro de una ventana. Esas ventanas tienen siempre tres botones en una esquina:

  • Minimizar: la oculta sin cerrarla. El programa sigue funcionando.
  • Maximizar / Restaurar: la agranda hasta ocupar toda la pantalla, o la devuelve a su tamaño anterior.
  • Cerrar: termina el programa. Si tenías cambios sin guardar, te pregunta.

Las ventanas se pueden mover, redimensionar y poner una al lado de la otra (arrastrando hacia un costado de la pantalla en Windows).

05Archivos y carpetas: organizar la información

Esta sección es probablemente la más importante de toda la unidad. Si aprendés a organizar bien tus archivos, te ahorrás cientos de horas a lo largo de tu vida.

¿Qué es un archivo?

Un archivo es cualquier conjunto de datos guardado en el disco con un nombre. Documento, foto, canción, video, programa: todo se guarda como archivo.

¿Qué es una carpeta?

Una carpeta (o directorio) es un contenedor que sirve para agrupar archivos relacionados entre sí. Las carpetas pueden contener archivos y también otras carpetas (subcarpetas), formando una estructura como un árbol.

🗄️ Una metáfora de toda la vida

Pensá en un archivero físico de oficina:

  • El archivero entero es tu disco.
  • Cada cajón es una carpeta principal (Documentos, Música, Fotos).
  • Cada bibliorato dentro del cajón es una subcarpeta (Trabajo, Estudio).
  • Cada hoja adentro del bibliorato es un archivo.

Igual que en un archivero, si no organizás bien, todo termina mezclado y nunca encontrás lo que buscás.

La ruta de un archivo

La ruta es la «dirección» completa que indica dónde está guardado un archivo. Por ejemplo:

C:\Usuarios\Maria\Documentos\Trabajo\CV_2026.docx

Esto se lee así: en el disco C, dentro de la carpeta Usuarios, en la subcarpeta Maria, dentro de Documentos, dentro de Trabajo, está el archivo CV_2026.docx. Cada barra ( \ en Windows, / en Linux y Mac) separa un nivel.

Extensiones de archivo

La extensión es lo que aparece después del punto en el nombre. Le dice al sistema qué tipo de archivo es y con qué programa abrirlo.

🏆 La regla de oro de los nombres

Poné nombres descriptivos. «Documento1.docx» no te dice nada. «CV_Maria_Lopez_2026.docx» te dice todo de un vistazo.

Tip pro: si vas a tener varias versiones del mismo archivo, agregale la fecha en formato AAAA-MM-DD. Por ejemplo: «Informe_2026-03-15.docx». Así, al ordenarlos por nombre, te quedan ordenados por fecha automáticamente.

06Comprimir y descomprimir archivos

Hay un tipo especial de archivo que conviene conocer: los archivos comprimidos, identificados por las extensiones .zip o .rar.

¿Qué es un archivo comprimido?

Es un archivo que contiene a otros archivos adentro, pero «apretados» para ocupar menos espacio. Funciona como una valija: en lugar de mandarte cinco prendas sueltas, las pongo en una valija, las acomodo y aprieto, y te mando solo la valija.

¿Para qué sirve?

  • Para mandar varios archivos juntos por correo o WhatsApp en un solo envío.
  • Para ahorrar espacio.
  • Para descargar conjuntos de archivos desde Internet (los programas que te bajás suelen venir en .zip).

¿Cómo se hace?

Para comprimir: seleccionás los archivos, clic derecho, «Enviar a → Carpeta comprimida» (Windows) o «Comprimir» (otros sistemas).

Para descomprimir: clic derecho sobre el .zip, «Extraer todo» o «Extraer aquí».

⚠️ Cuidado al descomprimir archivos de Internet

Muchos virus llegan disfrazados de archivos .zip o .rar bajados de páginas no confiables. Cuando descomprimís uno, ahí adentro puede haber un .exe o un .scr que es un programa malicioso. Si no estás seguro de la fuente, mejor no abras lo que extraigas, o pasalo por un antivirus antes.

07Instalar y desinstalar programas

Una vez que el sistema operativo está corriendo, vas a querer agregarle programas para tareas específicas. Eso se hace con un proceso llamado instalación.

Cómo se instalan los programas

  • Windows: se descarga un instalador (.exe o .msi), se hace doble clic, se siguen los pasos. También se puede usar la Microsoft Store.
  • macOS: se descarga un archivo .dmg y se arrastra la aplicación a la carpeta Aplicaciones. O App Store.
  • Linux: se usa el gestor de paquetes (Software Center, apt, dnf). Similar a la tienda de apps del celular.
  • Android / iOS: Play Store o App Store. Se busca la app, se toca «Instalar».

Por qué importa desinstalar lo que no usás

Cada programa instalado ocupa espacio en el disco, y algunos quedan funcionando en segundo plano consumiendo memoria RAM y batería, aunque no los uses.

Para desinstalar en Windows: Configuración → Aplicaciones → Aplicaciones instaladas. Buscás el programa, clic en Desinstalar.

⚠️ ¡Cuidado con lo que instalás!

La mayoría de los virus llegan a las computadoras porque el usuario los instaló sin querer. Tres reglas básicas:

  • Bajá programas solo de la página oficial o de tiendas oficiales (Microsoft Store, Google Play, App Store).
  • Cuando un instalador te pregunte si querés también instalar barras de búsqueda, antivirus extra o programas «recomendados», desmarcalos. Suele ser basura.
  • Si una página te dice que necesitás «un plugin especial» o «un actualizador» para ver un video, casi seguro es un virus. No lo bajes.

08Usuarios y permisos

Una computadora puede ser usada por varias personas. Para que cada una tenga su propio espacio, los sistemas operativos manejan el concepto de usuario.

¿Qué es un usuario?

Es una cuenta personal dentro de la computadora. Cada usuario tiene su propio escritorio, sus propios archivos, su propia configuración. Cuando arrancás la PC, te pide nombre y contraseña (o PIN o huella) para saber quién está usándola.

Tipos de usuario

  • Administrador: puede hacer todo. Instalar y desinstalar programas, cambiar configuraciones importantes, crear y eliminar otros usuarios.
  • Estándar: puede usar normalmente la computadora, pero no puede cambiar cosas críticas sin permiso del administrador.

Por qué importan los permisos

Si tu cuenta es administrador, cualquier programa que se ejecute también lo hace con poderes de administrador. Eso incluye a los virus: si te metés un virus mientras estás como administrador, ese virus puede hacer todo lo que vos podés hacer.

En cambio, si trabajás como usuario estándar, los virus tienen las manos atadas: no pueden modificar archivos del sistema sin que vos confirmes con una contraseña.

Por eso es buena práctica usar la computadora con una cuenta estándar para el día a día, y reservar la cuenta de administrador para cuando necesités instalar algo o cambiar configuración.

09Configuración de accesibilidad

Los sistemas operativos modernos tienen muchísimas opciones para adaptar la computadora a personas con distintas necesidades. Vale la pena conocerlas, tanto si te pueden servir a vos como para ayudar a familiares o amigos.

Para problemas de visión

  • Aumentar el tamaño del texto y los íconos.
  • Activar la lupa para ampliar zonas específicas.
  • Modo oscuro o alto contraste para reducir el cansancio visual.
  • Lectores de pantalla, que leen en voz alta (Narrador en Windows, VoiceOver en Mac, Orca en Linux).

Para problemas de audición

  • Subtítulos automáticos en videos.
  • Alertas visuales en lugar de sonoras.

Para dificultades motoras

  • Teclado en pantalla, manejable con un solo dedo.
  • Reconocimiento de voz para dictar texto.
  • Ajustes en la sensibilidad y velocidad del mouse.

Para todos

  • Brillo y temperatura de color (especialmente útil de noche).
  • Atajos personalizados para tareas frecuentes.
♿ La tecnología debe adaptarse a las personas

Antes, si tenías baja visión o dificultades motoras, usar una computadora era complicado. Hoy los sistemas operativos tienen tantas opciones de accesibilidad que casi cualquier persona puede usar una computadora con la configuración adecuada. Conocer estas opciones es importante: alguna vez en tu vida te pueden hacer falta a vos o a alguien cercano.

10Glosario de la unidad

  • Software: conjunto de programas, instrucciones y datos. La parte no física.
  • Sistema operativo (SO): software de base que controla el hardware y permite que el resto del software funcione.
  • Driver / controlador: pequeño programa que conecta el SO con un dispositivo específico.
  • Software libre: software que respeta las cuatro libertades (usar, estudiar, modificar, redistribuir).
  • Software propietario: software cuyo dueño controla todos los derechos.
  • Creative Commons: licencias para compartir obras con condiciones claras.
  • Archivo: conjunto de datos guardado con un nombre.
  • Carpeta / directorio: contenedor que agrupa archivos y otras carpetas.
  • Ruta: dirección completa donde se encuentra un archivo.
  • Extensión: las letras después del punto que indican el tipo.
  • Archivo comprimido (.zip / .rar): archivo que contiene a otros «apretados».
  • Instalar: agregar un programa al sistema.
  • Usuario: cuenta personal dentro de la computadora.
  • Administrador: usuario con permisos críticos.
  • Accesibilidad: opciones que adaptan la computadora a personas con distintas necesidades.

12Cierre de la unidad

Si llegaste hasta acá, ya entendés cómo se comunican el hardware y el software, sabés moverte por un sistema operativo, organizar tus archivos y proteger tu computadora de instalaciones peligrosas. Es muchísimo.

Antes de pasar a la próxima unidad, asegurate de que podés:

  • Diferenciar software de base, de aplicación y de programación con ejemplos propios.
  • Explicar qué hace un sistema operativo y nombrar al menos tres distintos.
  • Diferenciar software libre de software propietario.
  • Crear, renombrar, copiar, mover y eliminar archivos y carpetas con soltura.
  • Leer y entender una ruta de archivo.
  • Comprimir y descomprimir un .zip.
  • Identificar prácticas seguras al instalar programas.
