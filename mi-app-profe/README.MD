# 📚 Mi App Profe - Control de Alumnos y Asistencia

¡Bienvenido a **Mi App Profe**! Esta es una aplicación web interactiva y responsiva diseñada para la gestión del aula mediante el control de notas, el cálculo de métricas de rendimiento escolar y el seguimiento de asistencia en tiempo real.

Este proyecto ha sido desarrollado con fines de práctica avanzada, utilizando tecnologías web estándar sin dependencias externas (Vanilla Frontend) para consolidar conocimientos en lógica de programación y desarrollo web.

🚀 **[Ver Demo en Vivo](https://github.io)**

---

## ✅ Características Implementadas (Versión Final)

* **Interfaz Moderna y Adaptable:** Maquetación responsiva con CSS Grid y Flexbox que se visualiza perfectamente en dispositivos móviles, tablets y ordenadores.
* **Gestión de Calificaciones:** Registro dinámico de estudiantes con validación de formularios integrada (notas numéricas restrictivas entre 0 y 10).
* **Persistencia con `localStorage`:** Los datos se guardan de forma permanente en el navegador del usuario, evitando pérdidas de información al refrescar la página.
* **Estadísticas Analíticas en Tiempo Real:** Cálculo automático del total de alumnos matriculados y el promedio general del grupo.
* **Filtros Condicionales Visuales:** Uso de lógica en JavaScript para renderizar indicadores de color (verde para alumnos aprobados y rojo para reprobados).
* **Buscador en Tiempo Real:** Filtrado dinámico mediante arreglos de JavaScript (`.filter()`) que localiza estudiantes al instante según el texto ingresado.
* **Módulo de Asistencia Incorporado:** Control selectivo de asistencia mediante checkboxes con etiquetas dinámicas de "Presente" y "Ausente" en la lista general.
* **Exportación de Informes de Aula:** Botón dinámico que genera un archivo estructurado en formato `.csv`, totalmente compatible con Microsoft Excel, organizando el nombre, notas, estados y asistencia con codificación UTF-8 para preservar caracteres especiales.

---

## 💻 Tecnologías Utilizadas

* **HTML5:** Estructura semántica avanzada del sitio web.
* **CSS3:** Variables nativas (`:root`), transiciones suaves y diseño adaptativo.
* **JavaScript (ES6+):** Programación orientada a eventos, manipulación del DOM, gestión de estados y manejo de almacenamiento local.

## 🚀 Uso e Instalación Local

Para ejecutar el proyecto de forma local, sigue estos pasos:

1. Clona el repositorio oficial en tu máquina:
   ```bash
   git clone https://github.com
   ```
2. Navega a la carpeta correspondiente:
   ```bash
   cd mi-app-profe
   ```
3. Ejecuta el archivo principal abriendo `index.html` en cualquier navegador web moderno.
